### L4-S8 (statements)

**Question:** True or false? / Which of these statements related to the Eden Baysal Dental Trauma Index are true? / *Swipe the incorrect statements to the left and the true statements to the right.*

1. **FALSE**: The 2nd digit should be used to describe presence and types of Luxation injuries  
   _Explanation:_ False - the 2nd digit describes root fractures; luxation injuries are the 3rd digit.
2. **TRUE**: The 5th digit should be used to describe presence of Alveolar Fractures  
   _Explanation:_ True - the 5th digit (+/-) records the presence or absence of an alveolar process fracture.
3. **TRUE**: The 2nd digit should be used to describe presence and types of Root Fractures  
   _Explanation:_ True - the 2nd digit records root fractures (0 none, 1 apical, 2 middle, 3 cervical third).
4. **FALSE**: Palmer notation should be used to identify the traumatised teeth.  
   _Explanation:_ False - the index uses the FDI tooth code, not Palmer notation.
5. **TRUE**: 4th digit corresponds to the Maturity and shape of apex  
   _Explanation:_ True - the 4th digit records maturity and shape of the apex (i, m, r).
6. **TRUE**: The 1st digit should be used to describe presence and types of Crown fractures  
   _Explanation:_ True - the 1st digit records crown fractures (0-5).
